Aplicação web inspirada no iFood, simulando o fluxo completo de pedidos em um restaurante.

## 🚀 Funcionalidades
- Listagem de restaurantes
- Visualização de pratos
- Carrinho de compras
- Fluxo de checkout (entrega e pagamento)

## 🛠️ Tecnologias
- React
- TypeScript
- Styled Components
- APIs REST

## ▶️ Como rodar o projeto

```bash
npm install
npm run dev
